Lab Overview

This repository serves as technical documentation for exploratory testing on consumer off-the-shelf (COTS) hardware. The goal is to maximize device longevity, eliminate mandatory cloud dependencies, and unlock hidden software features.

Core Lab Philosophy

If you can't open it, patch it, and run it completely offline, you don't truly own it.

EXP-001: Overclocking & Custom Firmware on Linksys EA7500

Date: June 2026 | Status: Stable

Replacing the restrictive OEM stock firmware with OpenWrt to enable wire-speed SQM (Smart Queue Management) bufferbloat mitigation and network-wide ad-blocking via AdGuard Home.

Required Equipment

Item Specification Purpose
Linksys EA7500 Hardware Revision v2 Target device
FTDI USB-to-TTL Cable 3.3V Logic Level Serial communication unbricking fallback
Ethernet Cable Cat6 (1 meter) Direct TFTP deployment interface
Risk Assessment

Flashing partitions via command line runs the risk of corrupting the bootloader. Ensure a serial header is soldered onto the board before attempting partition modifications.

Installation Procedure

Execute the following steps over a wired connection with your host machine assigned a static IP address of 192.168.1.254.

# Step 1: Boot router into TFTP listening mode
# Hold down reset button while applying power for 12 seconds

# Step 2: Push the custom factory image via terminal
tftp 192.168.1.1
tftp> mode octet
tftp> put openwrt-23.05.0-mediatek-mt7621-linksys_ea7500-v2-squashfs-factory.bin
tftp> quit

# Step 3: Wait for system reboot (~3 minutes)
ping 192.168.1.1

Key Findings & Benchmark Results

  • Bufferbloat Rating: Improved from a grade of "C" to an "A+" under full load.
  • Memory Overhead: OpenWrt utilizes 42MB of RAM idling, compared to 118MB under stock firmware.
  • Wireless Stability: 5GHz transmission limits successfully adjusted to conform with local radio regulations without signal degradation.
